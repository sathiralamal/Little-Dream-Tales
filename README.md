# Little Dream Tales

Bedtime stories for kids 🌙 Calming animated tales with Benny the Bear, Bella the Bunny, and Charlie the Cat. Gentle narration and soft music for little ones, made to help them relax and feel ready for bed.

## Website

This is a simple static website built with HTML and CSS. Open `index.html` in a browser to view it. No build step or package installation is required.

- `index.html` — homepage and story characters
- `about.html` — about Little Dream Tales
- `privacy.html` — website privacy information
- `styles.css` — shared responsive styles

The Facebook page is [facebook.com/littledreamtales27](https://www.facebook.com/littledreamtales27).
